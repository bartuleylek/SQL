Subquery - Employees in Departments with High Average Salary

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
employee_name	varchar	NOT NULL
department	varchar	NOT NULL
salary	int	NOT NULL  

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return employees who work in departments whose average salary is greater than 65000.

Return the following columns:
- employee_id
- employee_name
- department
- salary
Return the result in any order.

Example
Input: Employees
employee_id	employee_name	department	salary
1	Alice	IT	80000
2	Bob	IT	70000
3	Carol	HR	50000
4	David	HR	60000
5	Emma	Finance	90000
6	Frank	Finance	70000  

Output
employee_id	employee_name	department	salary
1	Alice	IT	80000
2	Bob	IT	70000
5	Emma	Finance	90000
6	Frank	Finance	70000
