Subquery - Employee(s) with the Highest Salary

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
employee_name	varchar	NOT NULL
department	varchar	NOT NULL
salary	int	NOT NULL  

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return all employees whose salary is equal to the highest salary among all employees.

If multiple employees share the highest salary, return all of them.

Return the following columns:
- employee_id
- employee_name
- salary
Return the result in any order.

Example
Input: Employees
employee_id	employee_name	department	salary
1	Alice	IT	70000
2	Bob	HR	50000
3	Carol	Finance	90000
4	David	IT	60000
5	Emma	Sales	90000  

Output
employee_id	employee_name	salary
3	Carol	90000
5	Emma	90000
