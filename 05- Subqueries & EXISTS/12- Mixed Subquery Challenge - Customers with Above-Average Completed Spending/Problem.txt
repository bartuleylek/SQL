Mixed Subquery Challenge - Customers with Above-Average Completed Spending

Table: Customers
Column Name	Type	Constraints
customer_id	int	PRIMARY KEY
customer_name	varchar	NOT NULL  

customer_id is the primary key for this table.
Each row represents one customer.

Table: Orders
Column Name	Type	Constraints
order_id	int	PRIMARY KEY
customer_id	int	NOT NULL, FOREIGN KEY
status	varchar	NOT NULL
amount	decimal	NOT NULL  

order_id is the primary key for this table.
customer_id is a foreign key referencing Customers.customer_id.
Each row represents one order placed by a customer.

Problem
Write the SQL query to return customers whose total amount of completed orders is greater than the average completed-order total across customers who have at least one completed order.

Return the following columns:
- customer_id
- customer_name
- total_completed_amount
Return the result ordered by total_completed_amount from highest to lowest.

Example
Input: Customers
customer_id	customer_name
1	Alice
2	Bob
3	Carol
4	David  

Input: Orders
order_id	customer_id	status	amount
101	1	completed	600
102	1	completed	400
103	1	pending	500
104	2	completed	300
105	3	completed	700
106	3	completed	500
107	4	cancelled	900  

Completed totals:
Alice → 1000
Bob   → 300
Carol → 1200
David → no completed orders

Average completed total among customers with at least one completed order:
(1000 + 300 + 1200) / 3 = 833.33

Output
customer_id	customer_name	total_completed_amount
3	Carol	1200
1	Alice	1000
