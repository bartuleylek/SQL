Order By More Than One Column

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
name	varchar	NOT NULL
department	varchar	NOT NULL
salary	int	NOT NULL  

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return all employees:
- sorted alphabetically by department,
- and employees in the same department sorted by salary from highest to lowest.
Return the following columns:
- employee_id
- name
- department
- salary
Sort the result by department in ascending order and salary in descending order.

Example
Input: Employees
employee_id	name	department	salary
1	Alice	IT	75000
2	Bob	Finance	60000
3	Carol	Finance	80000
4	David	IT	50000  

Output
employee_id	name	department	salary
3	Carol	Finance	80000
2	Bob	Finance	60000
1	Alice	IT	75000
4	David	IT	50000
