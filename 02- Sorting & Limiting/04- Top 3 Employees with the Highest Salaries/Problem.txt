Top 3 Employees with the Highest Salaries

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
name	varchar	NOT NULL
salary	int	NOT NULL  

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return the three employees with the highest salaries.

Return the following columns:
- employee_id
- name
- salary
Sort the result by salary from highest to lowest.

Example
Input: Employees
employee_id	name	salary
1	Alice	70000
2	Bob	50000
3	Carol	90000
4	David	80000
5	Emma	60000  

Output
employee_id	name	salary
3	Carol	90000
4	David	80000
1	Alice	70000
