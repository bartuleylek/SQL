Ranking by Salary

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
name	varchar	NOT NULL
salary	int	NOT NULL  

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return all employees sorted by salary from highest to lowest.

Return the following columns:
- employee_id
- name
- salary
Sort the result by salary in descending order.

Example
Input: Employees
employee_id	name	salary
1	Alice	70000
2	Bob	50000
3	Carol	90000  

Output
employee_id	name	salary
3	Carol	90000
1	Alice	70000
2	Bob	50000
