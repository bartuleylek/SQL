Ranking by Name

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
name	varchar	NOT NULL
salary	int	NOT NULL  

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return all employees sorted alphabetically by name from A to Z.

Return the following columns:
- employee_id
- name
- salary
Sort the result by name in ascending order.

Example
Input: Employees
employee_id	name	salary
1	Carol	90000
2	Alice	70000
3	Bob	50000  

Output
employee_id	name	salary
2	Alice	70000
3	Bob	50000
1	Carol	90000
