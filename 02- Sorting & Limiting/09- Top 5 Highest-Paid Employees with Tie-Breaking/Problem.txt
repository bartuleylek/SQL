Top 5 Highest-Paid Employees with Tie-Breaking

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
name	varchar	NOT NULL
salary	int	NOT NULL  

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return the five highest-paid employees.

Return the following columns:
- employee_id
- name
- salary

Sort the result:
- by salary from highest to lowest,
- and if multiple employees have the same salary, by name alphabetically from A to Z.

Example
Input: Employees
employee_id	name	salary
1	Alice	90000
2	Bob	75000
3	Carol	90000
4	David	80000
5	Emma	75000
6	Frank	70000
7	Grace	85000  

Output
employee_id	name	salary
1	Alice	90000
3	Carol	90000
7	Grace	85000
4	David	80000
2	Bob	75000
