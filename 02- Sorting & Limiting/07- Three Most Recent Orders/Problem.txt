Three Most Recent Orders

Table: Orders
Column Name	Type	Constraints
order_id	int	PRIMARY KEY
customer_name	varchar	NOT NULL
order_date	date	NOT NULL
total_amount	decimal	NOT NULL  

order_id is the primary key for this table.
Each row represents one order.

Problem
Write the SQL query to return the three most recent orders.

Return the following columns:
- order_id
- customer_name
- order_date
Sort the result from newest to oldest.

Example
Input: Orders
order_id	customer_name	order_date	total_amount
101	Alice	2026-01-10	250
102	Bob	2026-01-15	400
103	Carol	2026-01-12	700
104	David	2026-01-20	300
105	Emma	2026-01-18	500  

Output
order_id	customer_name	order_date
104	David	2026-01-20
105	Emma	2026-01-18
102	Bob	2026-01-15
