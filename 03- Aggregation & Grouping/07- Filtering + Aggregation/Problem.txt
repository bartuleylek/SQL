Filtering + Aggregation

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
name	varchar	NOT NULL
department	varchar	NOT NULL
salary	int	NOT NULL  

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return the average salary of employees working in the IT department.

Return the following column:
- it_average_salary

Example
Input: Employees
employee_id	name	department	salary
1	Alice	IT	70000
2	Bob	HR	50000
3	Carol	IT	80000
4	David	Finance	60000  

Output
it_average_salary
75000
