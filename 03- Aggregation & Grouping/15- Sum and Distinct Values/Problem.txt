Table: Orders
Column Name	Type	Constraints
order_id	int	PRIMARY KEY
customer_id	int	NOT NULL
status	varchar	NOT NULL
amount	decimal	NOT NULL  

order_id is the primary key for this table.
Each row represents one order.

Problem
Write the SQL query to return summary statistics for orders whose status is either completed or shipped.

Return the following columns:
- order_count
- customer_count
- total_amount
- average_amount
Return all values in a single row.

Example
Input: Orders
order_id	customer_id	status	amount
101	1	completed	250
102	2	shipped	400
103	1	completed	150
104	3	cancelled	700
105	2	shipped	300  

Output
order_count	customer_count	total_amount	average_amount
4	2	1100	275
