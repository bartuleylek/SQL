Table: Orders
Column Name	Type	Constraints
order_id	int	PRIMARY KEY
customer_id	int	NOT NULL
status	varchar	NOT NULL
amount	decimal	NOT NULL  

order_id is the primary key for this table.
Each row represents one order.

Problem
Write the SQL query to return summary statistics for each order status, considering only orders whose amount is at least 100.

Return the following columns:
- status
- order_count
- total_amount
- average_amount
Return the result in any order.

Example
Input: Orders
order_id	customer_id	status	amount
101	1	completed	250
102	2	pending	80
103	1	completed	150
104	3	cancelled	700
105	2	pending	300
106	4	cancelled	50  

Output
status	order_count	total_amount	average_amount
completed	2	400	200
pending	1	300	300
cancelled	1	700	700
