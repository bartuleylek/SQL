Multiple Aggregates by Department

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
name	varchar	NOT NULL
department	varchar	NOT NULL
salary	int	NOT NULL  

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return summary statistics for each department.

Return the following columns:
- department
- employee_count
- average_salary
- highest_salary
Return the result in any order.

Example
Input: Employees
employee_id	name	department	salary
1	Alice	IT	70000
2	Bob	HR	50000
3	Carol	IT	80000
4	David	Finance	60000
5	Emma	IT	65000
6	Frank	HR	55000  

Output
department	employee_count	average_salary	highest_salary
IT	3	71666.67	80000
HR	2	52500	55000
Finance	1	60000	60000
