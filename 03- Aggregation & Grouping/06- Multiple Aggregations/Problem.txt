Multiple Aggregations

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
name	varchar	NOT NULL
department	varchar	NOT NULL
salary	int	NOT NULL  

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return:
- the total number of employees as employee_count,
- the total salary as total_salary,
- the average salary as average_salary,
- the lowest salary as lowest_salary,
- the highest salary as highest_salary.
Return all values in a single row.

Example
Input: Employees
employee_id	name	department	salary
1	Alice	IT	70000
2	Bob	HR	50000
3	Carol	Finance	90000
4	David	IT	60000  

Output
employee_count	total_salary	average_salary	lowest_salary	highest_salary
4	270000	67500	50000	90000
