Multiple Conditions

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
name	varchar	NOT NULL
department	varchar	NOT NULL
salary	int	NOT NULL

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return employees who work in the IT department and have a salary greater than 55000.

Return the following columns:
- employee_id
- name
- department
- salary
Return the result in any order.

Example
Input: Employees
employee_id	name	department	salary
1	Alice	IT	65000
2	Bob	HR	60000
3	Carol	IT	52000
4	David	IT	58000

Output
employee_id	name	department	salary
1	Alice	IT	65000
4	David	IT	58000
