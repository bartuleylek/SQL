LIKE Operator

Employees
| Column Name | Type    |
| ----------- | ------- |
| employee_id | int     |
| name        | varchar |
| department  | varchar |
| salary      | int     |

Write a query to return the employee_id and name of employees whose names start with the letter A.

Use the LIKE operator.

Return the result in any order.

Example

Input:

| employee_id | name  | department | salary |
| ----------: | ----- | ---------- | -----: |
|           1 | Alice | IT         |  65000 |
|           2 | Bob   | HR         |  45000 |
|           3 | Adam  | Finance    |  72000 |
|           4 | Clara | Sales      |  50000 |

Output:

| employee_id | name  |
| ----------: | ----- |
|           1 | Alice |
|           3 | Adam  |
