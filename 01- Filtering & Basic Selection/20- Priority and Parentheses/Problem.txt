| ----------- | ------- |
| employee_id | int     |
| name        | varchar |
| department  | varchar |

| manager_id  | int     |

Return the employee_id, name, department, and salary of employees who:

work in either IT or Finance,
have a salary between 60000 and 90000, inclusive,
and either have no manager or have a name starting with A.
