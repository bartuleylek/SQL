Department Filter

You are given the following table:

Employees
| Column Name | Type    |
| ----------- | ------- |
| employee_id | int     |
| name        | varchar |
| department  | varchar |
| salary      | int     |


employee_id is the primary key of this table.

Write a query to return the employee_id, name, and department of all employees who work in the IT department.

Return the result in any order.

Example

Input:

employee_id	name	department	salary
1	Alice	IT	65000
2	Bob	HR	45000
3	Carol	Finance	72000
4	David	IT	50000

Output:

employee_id	name	department
1	Alice	IT
4	David	IT
