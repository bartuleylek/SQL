IN Operator

You are given the following table:

Employees
| Column Name | Type    |
| ----------- | ------- |
| employee_id | int     |
| name        | varchar |
| department  | varchar |
| salary      | int     |

Write a query to return the employee_id, name, and department of employees who work in one of these departments:

IT
Finance
HR

Use the IN operator.

Return the result in any order.

Example

Input:

| employee_id | name  | department | salary |
| ----------: | ----- | ---------- | -----: |
|           1 | Alice | IT         |  65000 |
|           2 | Bob   | HR         |  45000 |
|           3 | Carol | Finance    |  72000 |
|           4 | David | Sales      |  50000 |

Output:

| employee_id | name  | department |
| ----------: | ----- | ---------- |
|           1 | Alice | IT         |
|           2 | Bob   | HR         |
|           3 | Carol | Finance    |
