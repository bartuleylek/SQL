IN Operator

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
name	varchar	NOT NULL
department	varchar	NOT NULL
salary	int	NOT NULL

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return employees who work in one of the following departments:
- IT
- Finance
- HR
Use the IN operator.

Return the following columns:
- employee_id
- name
- department
Return the result in any order.

Example
Input: Employees
employee_id	name	department	salary
1	Alice	IT	65000
2	Bob	HR	45000
3	Carol	Finance	72000
4	David	Sales	50000

Output
employee_id	name	department
1	Alice	IT
2	Bob	HR
3	Carol	Finance
