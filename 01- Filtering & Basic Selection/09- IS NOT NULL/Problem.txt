IS NOT NULL

Employees
| Column Name | Type    |
| ----------- | ------- |
| employee_id | int     |
| name        | varchar |
| manager_id  | int     |
| salary      | int     |

Write a query to return the employee_id, name, and manager_id of employees who have a manager.

Use IS NOT NULL.

Return the result in any order.

Example

Input:

| employee_id | name  | manager_id | salary |
| ----------: | ----- | ---------: | -----: |
|           1 | Alice |       NULL |  90000 |
|           2 | Bob   |          1 |  60000 |
|           3 | Carol |          1 |  65000 |
|           4 | David |       NULL |  85000 |

Output:

| employee_id | name  | manager_id |
| ----------: | ----- | ---------: |
|           2 | Bob   |          1 |
|           3 | Carol |          1 |
