IS NULL

Employees
| Column Name | Type    |
| ----------- | ------- |
| employee_id | int     |
| name        | varchar |
| manager_id  | int     |
| salary      | int     |

Write a query to return the employee_id and name of employees who do not have a manager.

Use IS NULL.

Example

Input:

| employee_id | name  | manager_id | salary |
| ----------: | ----- | ---------: | -----: |
|           1 | Alice |       NULL |  90000 |
|           2 | Bob   |          1 |  60000 |
|           3 | Carol |          1 |  65000 |
|           4 | David |       NULL |  85000 |

Output:

| employee_id | name  |
| ----------: | ----- |
|           1 | Alice |
|           4 | David |
