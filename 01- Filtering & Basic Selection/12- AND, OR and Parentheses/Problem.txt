AND, OR and Parentheses

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
name	varchar	NOT NULL
department	varchar	NOT NULL
salary	int	NOT NULL

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return employees who either:
- work in the IT department and have a salary greater than 60000,
- or work in the Finance department and have a salary greater than 70000.
Use parentheses to clearly separate the two condition groups.

Return the following columns:
- employee_id
- name
- department
- salary
Return the result in any order.

Example
Input: Employees
employee_id	name	department	salary
1	Alice	IT	65000
2	Bob	IT	55000
3	Carol	Finance	75000
4	David	Finance	68000
5	Emma	HR	90000

Output
employee_id	name	department	salary
1	Alice	IT	65000
3	Carol	Finance	75000
