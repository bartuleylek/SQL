Combined Conditions

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
name	varchar	NOT NULL
department	varchar	NOT NULL
salary	int	NOT NULL

employee_id is the primary key for this table.
Each row represents one employee.

Problem
Write the SQL query to return employees who work in either the IT or Finance department and have a salary greater than 60000.

Return the following columns:
- employee_id
- name
- department
- salary
Return the result in any order.

Example
Input: Employees
employee_id	name	department	salary
1	Alice	IT	65000
2	Bob	Finance	55000
3	Carol	HR	75000
4	David	Finance	72000
5	Emma	Sales	80000

Output
employee_id	name	department	salary
1	Alice	IT	65000
4	David	Finance	72000
