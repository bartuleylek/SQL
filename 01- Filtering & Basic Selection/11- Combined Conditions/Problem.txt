Combined Conditions

Employees
| Column Name | Type    |
| ----------- | ------- |
| employee_id | int     |
| name        | varchar |
| department  | varchar |
| salary      | int     |

Write a query to return the employee_id, name, department, and salary of employees who:

work in either the IT or Finance department,
and have a salary greater than 60000.

Return the result in any order.

Example

Input:

| employee_id | name  | department | salary |
| ----------: | ----- | ---------- | -----: |
|           1 | Alice | IT         |  65000 |
|           2 | Bob   | Finance    |  55000 |
|           3 | Carol | HR         |  75000 |
|           4 | David | Finance    |  72000 |
|           5 | Emma  | Sales      |  80000 |

Output:

| employee_id | name  | department | salary |
| ----------: | ----- | ---------- | -----: |
|           1 | Alice | IT         |  65000 |
|           4 | David | Finance    |  72000 |
