NOT IN

Employees
| Column Name | Type    |
| ----------- | ------- |
| employee_id | int     |
| name        | varchar |
| department  | varchar |
| salary      | int     |

Write a query to return the employee_id, name, and department of employees who work in neither the Sales department nor the HR department.

Use the NOT IN operator.

Return the result in any order.

Example

Input:

| employee_id | name  | department | salary |
| ----------: | ----- | ---------- | -----: |
|           1 | Alice | IT         |  65000 |
|           2 | Bob   | Sales      |  50000 |
|           3 | Carol | Finance    |  72000 |
|           4 | David | HR         |  55000 |
|           5 | Emma  | Marketing  |  60000 |

Output:

| employee_id | name  | department |
| ----------: | ----- | ---------- |
|           1 | Alice | IT         |
|           3 | Carol | Finance    |
|           5 | Emma  | Marketing  |
