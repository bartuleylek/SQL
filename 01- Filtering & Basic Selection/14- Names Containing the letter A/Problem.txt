Names Containing the Letter A

Employees
| Column Name | Type    |
| ----------- | ------- |
| employee_id | int     |
| name        | varchar |
| department  | varchar |
| salary      | int     |

Write a query to return the employee_id and name of employees whose names contain the letter a anywhere in the name.

Use the LIKE operator.

Return the result in any order.

Example

Input:

| employee_id | name  | department | salary |
| ----------: | ----- | ---------- | -----: |
|           1 | Alice | IT         |  65000 |
|           2 | Bob   | HR         |  50000 |
|           3 | Clara | Finance    |  72000 |
|           4 | David | Sales      |  58000 |

Output:

| employee_id | name  |
| ----------: | ----- |
|           1 | Alice |
|           3 | Clara |
|           4 | David |
