Combined Filtering

Employees
| Column Name | Type    |
| ----------- | ------- |
| employee_id | int     |
| name        | varchar |
| department  | varchar |
| salary      | int     |
| manager_id  | int     |

Write a query to return the employee_id, name, and salary of employees who:

work in either the IT or Finance department,
have a salary between 50000 and 80000, inclusive,
and have a manager.

Return the result in any order.

Example

Input:

| employee_id | name  | department | salary | manager_id |
| ----------: | ----- | ---------- | -----: | ---------: |
|           1 | Alice | IT         |  65000 |         10 |
|           2 | Bob   | Finance    |  45000 |         11 |
|           3 | Carol | IT         |  80000 |       NULL |
|           4 | David | Finance    |  70000 |         12 |
|           5 | Emma  | HR         |  60000 |         13 |

Output:

| employee_id | name  | salary |
| ----------: | ----- | -----: |
|           1 | Alice |  65000 |
|           4 | David |  70000 |
