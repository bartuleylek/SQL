ON vs WHERE - Critical LEFT JOIN Difference

Table: Customers
Column Name	Type	Constraints
customer_id	int	PRIMARY KEY
customer_name	varchar	NOT NULL

customer_id is the primary key for this table.
Each row represents one customer.

Table: Orders
Column Name	Type	Constraints
order_id	int	PRIMARY KEY
customer_id	int	NOT NULL, FOREIGN KEY
status	varchar	NOT NULL
amount	decimal	NOT NULL

order_id is the primary key for this table.
customer_id is a foreign key referencing Customers.customer_id.
Each row represents one order placed by a customer.

Problem
Write the SQL query to return every customer together with the number of completed orders they have placed.

Customers who have never placed a completed order must also be included with an order_count of 0.

Return the following columns:
- customer_id
- customer_name
- order_count
Return the result in any order.

Example
Input: Customers
customer_id	customer_name
1	Alice
2	Bob
3	Carol
4	David

Input: Orders
order_id	customer_id	status	amount
101	1	completed	250
102	1	pending	400
103	1	completed	150
104	2	cancelled	700
105	3	completed	300

Output
customer_id	customer_name	order_count
1	Alice	2
2	Bob	0
3	Carol	1
4	David	0
