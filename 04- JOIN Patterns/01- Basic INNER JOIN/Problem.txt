Basic INNER JOIN

Table: Customers
Column Name	Type	Constraints
customer_id	int	PRIMARY KEY
customer_name	varchar	NOT NULL
city	varchar	NOT NULL


customer_id is the primary key for this table.
Each row represents one customer.

Table: Orders
Column Name	Type	Constraints
order_id	int	PRIMARY KEY
customer_id	int	NOT NULL, FOREIGN KEY
order_date	date	NOT NULL
amount	decimal	NOT NULL


order_id is the primary key for this table.
customer_id is a foreign key referencing Customers.customer_id.
Each row represents one order placed by a customer.

Problem
Write the SQL query to return the details of every order together with the name of the customer who placed it.

Return the following columns:
- order_id
- customer_name
- order_date
- amount
Return the result in any order.

Example
Input: Customers
customer_id	customer_name	city
1	Alice	London
2	Bob	Paris
3	Carol	Berlin


Input: Orders
order_id	customer_id	order_date	amount
101	1	2026-01-10	250
102	2	2026-01-11	400
103	1	2026-01-12	150
104	3	2026-01-13	700


Output
order_id	customer_name	order_date	amount
101	Alice	2026-01-10	250
102	Bob	2026-01-11	400
103	Alice	2026-01-12	150
104	Carol	2026-01-13	700
