SELF JOIN

Table: Employees
Column Name	Type	Constraints
employee_id	int	PRIMARY KEY
employee_name	varchar	NOT NULL
manager_id	int	NULL, FOREIGN KEY

employee_id is the primary key for this table.
manager_id is a foreign key referencing Employees.employee_id.
Each row represents one employee.
An employee may have another employee as their manager.
manager_id can be NULL if the employee has no manager.

Problem
Write the SQL query to return each employee together with the name of their manager.

Return the following columns:
- employee_name
- manager_name
Include only employees who have a manager.

Return the result in any order.

Example
Input: Employees
employee_id	employee_name	manager_id
1	Alice	NULL
2	Bob	1
3	Carol	1
4	David	2
5	Emma	2

Output
employee_name	manager_name
Bob	Alice
Carol	Alice
David	Bob
Emma	Bob
